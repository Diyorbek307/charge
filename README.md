# ONE CHARGE UZ

Прототип национальной платформы зарядной инфраструктуры для электромобилей в Узбекистане.

**Живая демонстрация:** https://charge-qogf.onrender.com

Шесть приложений работают поверх одной базы данных и синхронизируются между собой в реальном
времени: действие в одном портале сразу видно во всех остальных, без перезагрузки страницы.

---

## Демо-доступы

У каждого портала своя учётная запись и свой пароль — пароль одного портала не подходит
к другому. На экране входа есть кнопка «Заполнить», которая подставляет нужную пару.

| Портал | Логин | Пароль |
| --- | --- | --- |
| Driver App | `+998901234567` | `Driver2026` |
| Operator Portal | `operator@greencharge.uz` | `Operator2026` |
| Admin Control Center | `admin@onecharge.uz` | `Admin2026` |
| Business Portal | `fleet@uzauto.uz` | `Business2026` |
| Partner API | `partner@onecharge.uz` | `Partner2026` |

## Как посмотреть синхронизацию

Самый наглядный сценарий — кнопка **«Сравнить порталы»** внизу слева на главной. Она открывает
два портала бок о бок в одном окне.

1. Слева выберите **Driver App**, справа — **Operator Portal**, войдите в оба.
2. Слева: карта → маркер станции → «Начать зарядку» → режим «Удалённо» → «Подтвердить».
3. Справа коннектор сразу станет занятым, сессия появится в таблице, счётчик кВт·ч пойдёт вверх.

Кнопка **Sync** внизу справа открывает монитор: живой статус соединения, кто в каких порталах
залогинен и лента событий, перетекающих между приложениями.

## Возможности

**Порталы**
- **Driver App** — карта станций, запуск и остановка зарядки, история, кошелёк, планировщик поездок
- **Operator Portal** — станции, EVSE, сессии, тарифы, финансы, оповещения
- **Admin Control Center** — операторы, пользователи, платежи, settlement, fraud, CDR, аудит
- **Business Portal** — автопарк, сотрудники, лимиты, расходы, отчёты
- **Partner API** — документация, песочница, webhooks
- **Архитектура** — интерактивная схема экосистемы

**Платформа**
- Общая база и REST API; live-синхронизация через Server-Sent Events
- Отдельная авторизация на портал: scrypt-хеши паролей, bearer-токены
- Двухфакторная аутентификация (TOTP, RFC 6238) — совместима с Google Authenticator
- Вебхуки для партнёров с HMAC-SHA256 подписью и журналом доставок
- Экспорт отчётов в CSV и PDF с историей выгрузок
- Три языка интерфейса: UZ / RU / EN
- Тёмная тема, командная палитра (Ctrl+K), офлайн-режим (PWA)
- **Живая очередь к станции**: когда все коннекторы заняты, водитель встаёт в очередь; освободившийся
  коннектор 5 минут удерживается за первым в очереди, ему приходит уведомление, а занять его чужому
  нельзя
- **Зелёные часы**: цена зависит от часа по Ташкенту — ×0.7 ночью (23:00–07:00), ×0.9 днём, ×1.25 в
  вечерний пик — и фиксируется в момент старта. На карточке станции подсказка, когда выгоднее
  заряжаться, в эко-профиле — график цены на сутки
- **Жалобы водителей**: «Сообщить о проблеме» создаёт оповещение у оператора именно этой сети;
  упоминание угрозы безопасности поднимает его до критического. Не чаще одной жалобы на станцию
  раз в 10 минут. Оператор видит только оповещения своей сети
- **Эко-профиль**: сэкономленный CO₂ относительно бензина, эквивалент в деревьях и километрах,
  достижения и таблица лидеров (только имя и инициал)

## Запуск локально

```bash
npm install
npm run build
npm start
```

Приложение поднимется на http://localhost:3000 — Express отдаёт собранный фронтенд и API.

Для разработки удобнее два процесса:

```bash
npm start        # API на :3000
npm run dev      # Vite с горячей перезагрузкой на :5173 (проксирует /api на :3000)
```

Иконки PWA пересобираются скриптом `node scripts/make-icons.mjs`.

### Тесты

```bash
npm test
```

34 сквозных теста API на встроенном `node:test`, без зависимостей. Каждый прогон поднимает
настоящий сервер во временной папке данных — локальная база не затрагивается. Покрыты вход и
изоляция порталов, 2FA, сессии зарядки, границы прав операторов, кошелёк, вебхуки, отчёты, очередь,
тарифы, жалобы и эко-профиль.

Написаны они против *правильного* поведения и при первом запуске нашли семь реальных дыр:
водитель мог остановить чужую зарядку, один аккаунт — занять все коннекторы, пустой кошелёк —
заряжаться бесплатно, оператор — управлять станциями и сессиями конкурента, коннектор можно было
вручную застрять в «занято», а тики счётчика принимались без авторизации. Всё исправлено.

## Устройство

```
server/            Бэкенд
  seed.js            Демо-данные и схема (SCHEMA_VERSION — смена сбрасывает базу)
  db.js              Файловое JSON-хранилище с атомарной записью
  api.js             REST-эндпоинты и SSE-канал
  totp.js            TOTP по RFC 6238
tests/
  api.test.mjs       Сквозные тесты API
server.js          Express: API + статика + SPA-fallback

src/
  lib/api.ts         Типизированный клиент
  lib/sync.tsx       Общее состояние, SSE, токены по порталам
  lib/live.ts        Переходник между базой и формами данных, которые ждут экраны
  lib/i18n.tsx       Переводы
  lib/export.ts      CSV и PDF
  components/        Порталы и общие компоненты
```

### Решения, о которых стоит знать

**Хранилище — файловый JSON, а не SQLite.** На бесплатном тарифе Render диск всё равно
эфемерный, так что нативная СУБД не дала бы настоящей долговечности, зато добавила бы риск
падения деплоя. При перезапуске инстанса база пересоздаётся из `seed.js`.

**Вебхуки подписываются, но не отправляются.** Сервис публично доступен, и POST на произвольный
адрес из формы превратил бы его в SSRF-инструмент. Партнёр получает точное тело и заголовки
с подписью — этого достаточно, чтобы проверить интеграцию. Реальная доставка должна жить
в изолированном воркере с allowlist и очередью ретраев.

**PDF рисуется на canvas, а не снимается с DOM.** Встроенные шрифты jsPDF не поддерживают
кириллицу, а html2canvas не умеет разбирать цвета `oklch()`, которые генерирует Tailwind 4.
Отрисовка таблицы вручную решает обе проблемы; картинка вставляется как JPEG, иначе jsPDF
встраивает PNG без сжатия и отчёт на пять строк весит мегабайты.

**Права проверяются на сервере, а не в интерфейсе.** Остановить сессию может только её владелец,
оператор той сети, где стоит станция, или администратор. Оператор видит и меняет только свои
станции. Зарядка не стартует, если кошелёк не покрывает минимум 5 кВт·ч по тарифу коннектора.

**Переводы падают на русский.** Русский — исходный язык; недостающий ключ показывает русский
текст, а не имя ключа. Переведены оболочка, экраны входа и навигация с заголовками страниц
в дашбордах; тела страниц пока остаются русскими.

## Деплой

Хостится на Render как Node Web Service. Сборка запускается сама через `postinstall`, поэтому
менять команды в дашборде не нужно. Каждый `git push` в `main` вызывает передеплой.

> Бесплатный инстанс засыпает после ~15 минут простоя: первый запрос после паузы может занять
> около минуты, а база при этом сбрасывается к демо-данным.
