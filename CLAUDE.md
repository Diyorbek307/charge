# Voli — правила для Claude

Перед работой прочитай [`docs/HANDOFF.md`](docs/HANDOFF.md): там всё о проекте, что сделано и что осталось.

## Владелец
- Пишет по-русски, отвечай по-русски, просто и по шагам: он не программист.
- Часто пишет в английской раскладке (`cltkfq` = «сделай») или голосом — расшифровывай.
- Не проси присылать в чат пароли, ключи API, пароли SMTP, адреса баз: он вписывает их сам в Render, Codemagic, Firebase.
- За него не плати, не вводи пароли и не входи в рабочую админку app.voli.uz.

## Работа с кодом
- После изменений: `npx tsc --noEmit -p .`, `npm test`; для экранов — `npm run build && npx playwright test -c pw.local.tmp.mjs`.
- Когда всё зелёное — коммить и пушь в `main` сразу, не спрашивая (деплой на Render автоматический).
- Подпись коммитов: `git -c user.name="Diyorbek307" -c user.email="diyorbekmustafaev7@gmail.com" commit`.
- Цвета: жёлтый `#FFC83D`, почти чёрный `#111`, шрифт Inter. Зелёного нет.
- Каждую новую русскую строку интерфейса добавляй в `src/lib/phrases/uz.json` и `en.json`.
- Не меняй `SCHEMA_VERSION` в `server/seed.js` без нужды: это пересоздаёт базу.
- Не открывай заново демо-логины сотрудников на рабочем сервере (см. «Безопасность» в HANDOFF).
- Файлы в `signing/` и `marketing/` не в git — не удаляй и не публикуй их.
