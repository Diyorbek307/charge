## Осталось сделать

**Пачка 3 — сети и деньги**
1. Акты и счета сетям на комиссию раз в месяц (PDF), по данным `server/direct.js` (журнал `directLedger`).
2. Надёжность станций: доля времени онлайн, отказы при старте, время ремонта → «надёжность» на карточке, рейтинг сетей в админке.
3. Скидки и акции от сетей: сеть сама создаёт акцию («−20% ночью», «первая зарядка бесплатно») и оплачивает её; вкладка «Скидки» и значок «%» на карте.
4. Напоминания: мало денег на балансе сети, завтра срок оплаты долга.
5. Фото в отзывах о станции.

**Пачка 4 — к запуску**
1. Заготовка нативного приложения (Capacitor) для App Store / Google Play.
2. Ежедневная сверка платежей Payme/Click с нашими записями.
3. Autocharge: станция узнаёт машину (idTag по MAC) и запускает зарядку сама.
4. Панель для инвесторов: оборот, активные водители, рост по месяцам.
5. Скрипт резервных копий базы и проверка восстановления.

## Как проверять

```bash

npx vite build
npm test
```

e2e: `npx playwright test` (локально использовался конфиг с каналом Edge).

## Правила проекта

- Коммитить и пушить в `main` без вопросов, но только когда всё зелёное.
- Интерфейс на русском — это исходный язык; переводы в `src/lib/phrases/{en,uz}.json` (точные строки и шаблоны с `{0}`).
- Цвета бренда: жёлтый `#FFC83D` / `#FFB000`, текст на жёлтом — почти чёрный `#111`; серые — нейтральные.
- Своих станций у Zaryad24 нет: только сети-партнёры по договору.
