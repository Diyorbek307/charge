## 1. Что такое Voli

Агрегатор зарядных станций для электромобилей в Узбекистане. **Своих станций нет**: Voli
подключает сети-партнёров (OCPI 2.2.1, своё API, OCPP или «только карта»). Водитель видит
станции всех сетей на одной карте, запускает зарядку и платит из одного кошелька.
Voli зарабатывает комиссией с зарядок, которые привёл.

Шесть частей на одной базе, синхронизация вживую:

| Часть | Для кого | Адрес |
|---|---|---|
| Лендинг | все | https://voli.uz |
| Driver App | водители (веб + приложение из магазинов) | https://app.voli.uz/?portal=driver |
| Operator Portal | сети-партнёры | `?portal=operator` |
| Admin Control Center | команда Voli | `?portal=admin` |
| Business Portal | автопарки и такси | `?portal=business` |
| Partner API | разработчики сетей | `?portal=api` |

Язык интерфейса — русский (исходный), плюс узбекский и английский.

## 3. Где работает

- **Render**, сервис `charge` — тариф **Starter** ($7/мес): Node-сервер отдаёт и сайт, и API.
  Платный тариф нужен, в том числе чтобы почта уходила: бесплатный блокирует SMTP-порты.
- **Render Postgres** `voli-db` — тариф Basic 256 МБ ($6/мес). Данные — один JSONB-документ.
- Деплой — автоматически при пуше в `main`.
- Переменные окружения задаются в Render → charge → Environment. Полный список с пояснениями:
  [`deploy/.env.example`](../deploy/.env.example). Секреты в чат и в git не попадают.

Сейчас заданы (по словам владельца): `DATABASE_URL`, SMTP (`smtp.mail.ru`, пароль приложения
VK WorkSpace), `ADMIN_EMAIL`, `ADMIN_PASSWORD`. **Не заданы**: Payme/Click, Eskiz,
`ANTHROPIC_API_KEY`, `GOOGLE_CLIENT_ID`, `APPLE_CLIENT_ID`, FCM/APNs.

## 4. Что сделано (по темам)

**Водитель**
- Приветствие с фото (машина у зарядки на фоне Ташкента) и вход **по коду**: телефон → SMS,
  почта → письмо; новичок вводит имя — аккаунт создан. Вход по паролю — запасной.
  Google и Apple — кнопки появятся, когда заданы ключи (`server/signin.js`, `src/components/driver/DriverAuth.tsx`).
- Карта всех сетей, фильтры, кластеры; кнопки «Ближайшая свободная», «Дешевле рядом», «Как в прошлый раз».
- Карточка станции: фото сверху, лента до 6 фото, «Надёжность N%», «Цена сегодня» по часам,
  разъёмы с кнопкой «Зарядиться» у каждого. Цены везде с учётом тарифа по времени суток
  (`src/lib/tariff.ts`) — ровно то, что спишет сервер.
- Заставка «зарядки» логотипа (`driver/Splash.tsx`) и тёмный вход с фото и стеклянной карточкой.
- Экран зарядки: машина в жёлтой подсветке, батарея, процент, мощность, энергия, стоимость.
- QR-старт, бронь и очередь, цели зарядки, навигатор с голосом и камерами, офлайн-трассы,
  «свободно к приезду», здоровье батареи, Voli Plus, награды и бонусы, «Приведи друга»,
  зарядка в долг с проверкой лица, оплата напрямую сетям, семейный кошелёк, чат поддержки
  с ИИ-агентами, SOS, удаление аккаунта (Google и Apple требуют), тёмная тема.

**Сети и бизнес**
- Кабинет сети: станции, финансы, оповещения, вебхуки, тарифы и акции, QR-наклейки, фото станции.
- Акции: сети создают свои, Voli — общие кампании из админки (`server/promos.js`); пуш водителям
  с согласием на рекламу.
- Автопарки: лимиты, тариф для такси, отчёты.
- Подключение: OCPI 2.2.1, Voli API, OCPP 1.6/2.0.1, «только карта».

**Админка**
- Пользователи, сети, финансы, заявки с лендинга, акции, ИИ-агенты поддержки,
  «Управление платформой» (50+ настроек без выпуска), состояние системы и тест почты, журнал действий.
- «Обзор» начинается со строки «Требует внимания» (SOS, чаты, сбои, заявки, сети на проверке,
  долги, зависшие платежи — кнопкой в раздел); в меню красные счётчики (`server/inbox.js`).
- Поиск по всей админке: Ctrl+K или «Поиск» в меню (`AdminSearch.tsx`, `/admin/search`).
- «Аналитика»: рост водителей (активные, воронка, когорты по неделям), спрос, который сеть не
  закрывает (`server/demand.js`), надёжность станций и рейтинг сетей (`server/reliability.js`).
- «Для инвестора»: оборот и комиссия по месяцам, годовой темп, средний рост (`investorFor`).
- «Акции» → «Что принесли акции»: выручка, новые водители, выручка на 1 сум скидки.
- «Платежи» → «Сверка с провайдером»: CSV-выписка Payme/Click против наших пополнений (`server/reconcile.js`).
- «Расчёты» и кабинет сети → «Акт PDF» за каждый закрытый месяц (`src/lib/act.ts`).
- «Расчёты» → «Отметить выплату»: месяц сети считается выплаченным только после отметки банковского
  перевода (дата, сумма, номер п/п); через 3 дня после 2-го числа — «Просрочена» и ежедневное
  напоминание в Telegram (`server/payouts.js`). Сеть видит дату и номер п/п в своём кабинете.
- Paynet: пополнение по 8-значному номеру счёта из окна «Пополнить» (`server/paynet.js`,
  JSON-RPC провайдера; коды ошибок сверить с документацией Paynet перед запуском).
- Выгрузка в Excel (CSV) на всех таблицах.

**Безопасность** (последние коммиты, `server/db.js`, `server/api.js`, `server/adminBootstrap.js`)
- На рабочем сервере (Render или `NODE_ENV=production`) все демо-логины сотрудников закрыты;
  публикуется только демо-вход водителя. `DEMO_STAFF=true` временно открывает демо-кабинеты
  сети, автопарка и партнёра для показа (админ — никогда).
- Админ — из `ADMIN_EMAIL` / `ADMIN_PASSWORD`; у **всех сотрудников обязателен 2FA**,
  без него кабинет показывает только экран подключения Google Authenticator.
- Письмо о каждом входе в админку; `ADMIN_ALLOWED_IPS`; админ выходит после 30 мин простоя и через 12 ч.
- Токены входа хранятся только хешем SHA-256; ограничения на подбор пароля, 2FA и кодов входа;
  CSP и заголовки безопасности.

**Магазины** (подробно — [`docs/stores.md`](stores.md))

## 5. Что осталось (по важности)

1. **Магазины**: дождаться D-U-N-S для VOLI ENERGY LLC → Apple Developer (организация, $99) и
   Google Play (организация, $25). Потом вписать `APP_STORE_APPLE_ID` в `codemagic.yaml`.
2. **Первая сеть-партнёр** — пока станции демо, приложение держать в закрытом тестировании.
3. **Оплата**: договоры Payme, Click (как «пополнение лицевого счёта»), Paynet (поставщик услуг), ключи в Render; `DEMO_MODE=false` на рабочем сервере
   (тогда выключатся демо-коды SMS и песочница оплаты).
4. **SMS (Eskiz)**: начато. Eskiz работает только с юрлицами: добавить реквизиты VOLI ENERGY,
   «Запрос договора», шаблон `Voli: kod %d. Hech kimga aytmang. Никому не сообщайте код.` (62 знака — одна SMS),
   ник «Voli», затем `ESKIZ_EMAIL`, `ESKIZ_PASSWORD`, `ESKIZ_FROM` в Render — **только после**
   одобрения договора и шаблона.
5. **Нативные уведомления** (Firebase FCM + APNs) — в приложении из магазина пуш пока не приходит.
6. **Вход Google/Apple внутри приложения из магазина** — нужен нативный плагин; на сайте уже работает по ключам.
7. **ИИ-поддержка на Claude** — задать `ANTHROPIC_API_KEY` (сейчас отвечают шаблоны).
8. **Токен входа в защищённой cookie** вместо localStorage — перед запуском с реальными деньгами.
9. Юристу — проверить документы; дописать ОКЭД, счёт, банк, МФО, телефон.
10. Мелочи: подписи на карте иногда налезают друг на друга; названия акций сетей — только на языке сети.
11. Раньше документы были на ООО «ENESSES»; с 05.11.2026 всё на «VOLI ENERGY» — старое юрлицо нигде не использовать.
12. Владельцу: проверить, что в Render → voli-db включены резервные копии; заказать внешний пентест.

## Резервные копии и восстановление

Сервер каждую ночь (3–6 утра по Ташкенту) делает копию всей базы, сразу проверяет её по живым данным и хранит 14 последних (в Postgres — отдельная таблица `onecharge_backups`). Список, «Сделать копию сейчас» и «Скачать» — в админке, «Состояние системы». С `BACKUP_KEY` копия ещё и уходит зашифрованной письмом в `BACKUP_EMAIL`. Неудача — сигнал в Telegram и на почту.

Восстановить: остановить сервис на Render (Suspend), затем на компьютере
`node scripts/restore-backup.mjs <копия.json.gz или .voli>` — покажет, что внутри, ничего не меняя;
с `--yes` и `DATABASE_URL` (внешний адрес базы из Render) запишет копию как рабочую базу. Для `.voli` нужен тот же `BACKUP_KEY`. Потом снова запустить сервис.

## 7. Как работать с кодом

```bash
npm install            # ставит зависимости и собирает сайт
npm start              # сервер на http://localhost:3000 (демо-данные, все демо-логины работают)
npx tsc --noEmit -p .  # типы
npm test               # серверные тесты (~212, ~5 минут)
npm run build && npx playwright test -c pw.local.tmp.mjs   # браузерные (14), через Edge
```

- Браузерные тесты гоняют собранный `dist/` — **сначала `npm run build`**.
- `pw.local.tmp.mjs` (в корне, не в git) — тот же конфиг Playwright с `channel: 'msedge'`,
  потому что у Playwright нет своего Chromium на этой машине. Содержимое:
  `import base from './playwright.config.mjs'; export default { ...base, projects: base.projects.map(p => ({ ...p, use: { ...p.use, channel: 'msedge' } })) };`
- Тест рабочего режима (закрытые демо-логины, 2FA) — `tests/production-guard.test.mjs`.
- Демо-логины локально: водитель `+998901234567` / `Driver2026`, сеть `operator@greencharge.uz` / `Operator2026`,
  админ `admin@voli.uz` / `Admin2026`, автопарк `fleet@uzauto.uz` / `Business2026`, партнёр `partner@voli.uz` / `Partner2026`.
  На рабочем сервере работает только водительский.

## 8. Стиль и договорённости

- Цвета бренда: жёлтый `#FFC83D` / `#FFB000`, почти чёрный `#111`, шрифт Inter. Зелёный не используем.
- Логотип: тёмная левая черта V, жёлтое «лезвие» справа, жёлтая точка над i (`src/landing/Logo.tsx`).
- Новые русские строки интерфейса — сразу добавлять в `src/lib/phrases/uz.json` и `en.json`.
- Комментарии в коде — по-английски, коротко, объясняют «почему».
- Владелец пишет по-русски, часто голосом или в неправильной раскладке (`ghbdtn` = «привет»).
- Коммиты — сразу в `main` и пуш, без вопросов, когда тесты зелёные.
